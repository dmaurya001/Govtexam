## 🌐 छात्रों को लिंक कैसे भेजें? (How to Share Link with Students)

आप इस क्विज को इंटरनेट पर **बिल्कुल फ्री** में लाइव कर सकते हैं और उसका लिंक छात्रों को व्हाट्सएप/टेलीग्राम पर भेज सकते हैं:

### तरीका 1: Netlify Drop (सबसे आसान और तेज़ - सिर्फ 15 सेकंड में)
1. अपने ब्राउज़र में खोलें: **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. अपने कंप्यूटर के इस फोल्डर (`e:\New project`) को खींचकर (Drag & Drop) नेटलिफ्ट्री की स्क्रीन पर छोड़ दें।
3. तुरंत 15 सेकंड में आपको एक लाइव लिंक मिल जाएगा (जैसे: `https://bsc-nursing-exam.netlify.app`)।
4. इस लिंक को कॉपी करें और अपने सभी छात्रों को भेज दें!

### तरीका 2: GitHub Pages (100% मुफ़्त हमेशा के लिए)
1. GitHub पर एक नया रिपॉजिटरी बनाएँ।
2. इस फोल्डर की फाइलें (`index.html`, `style.css`, `app.js`, `questions.js`) अपलोड करें।
3. **Settings -> Pages** में जाएँ और `Deploy from a branch` चुनकर `main` सेव करें।
4. आपको `https://<your-username>.github.io/<repo-name>` का स्थायी लिंक मिल जाएगा।

### तरीका 3: अपने कंप्यूटर पर तुरंत खोलने के लिए
- बस अपने कंप्यूटर में `e:\New project\index.html` फाइल पर डबल-क्लिक करें, यह तुरंत आपके ब्राउज़र में खुल जाएगी!
